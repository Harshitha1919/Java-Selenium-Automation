DAY 1 – SELENIUM INTERVIEW QUESTIONS AND ANSWERS

1. What is Selenium?

Selenium is an open-source automation testing tool used to automate web browsers. It helps testers perform actions such as clicking buttons, entering text, submitting forms and testing web applications automatically.

2. What is Software Testing?

Software testing is the process of checking whether an application works according to its requirements. It helps identify bugs, errors and defects before delivering the software to users.

3. What is Automation Testing?

Automation testing is the process of using tools and programming scripts to execute test cases automatically without performing every step manually.

4. What is the difference between Manual Testing and Automation Testing?

Manual Testing:
- Testing is performed manually by a human tester.
- It takes more time for repetitive tasks.
- Programming knowledge is not required.
- Suitable for exploratory and usability testing.

Automation Testing:
- Testing is performed using automation scripts.
- It saves time when executing repetitive test cases.
- Programming knowledge is generally required.
- Suitable for regression and repetitive testing.

5. Why do we use Selenium?

Selenium is used because:

1. It is an open-source tool.
2. It supports multiple browsers.
3. It supports multiple programming languages.
4. It reduces repetitive manual testing work.
5. It supports cross-browser testing.
6. It can be integrated with testing frameworks.

6. What are the components of Selenium?

Selenium has three commonly discussed components:

Selenium IDE:
- Records and plays back browser actions.
- Useful for simple automation tasks.

Selenium WebDriver:
- Automates browsers using programming languages.
- Used for writing automation scripts.

Selenium Grid:
- Executes tests on multiple machines and browsers.
- Supports parallel execution.

7. What is Selenium WebDriver?

Selenium WebDriver is a component of Selenium used to automate web browsers. It allows us to interact with web elements such as buttons, text boxes, links and dropdowns using programming languages like Java.

8. Which programming languages are supported by Selenium?

- Java
- Python
- C#
- JavaScript
- Ruby

9. Which browsers are supported by Selenium?

- Google Chrome
- Mozilla Firefox
- Microsoft Edge
- Safari

10. What is Selenium Grid?

Selenium Grid is used to execute automation test cases across multiple browsers, operating systems and machines. It supports parallel execution and reduces overall testing time.

11. What is Cross-Browser Testing?

Cross-browser testing is the process of testing a web application on different browsers to ensure that it works correctly.

Example: Testing the same login page on Chrome, Firefox and Edge.

12. What are the advantages of Selenium?

1. Open-source and freely available.
2. Supports multiple programming languages.
3. Supports different browsers.
4. Supports multiple operating systems.
5. Integrates with TestNG and JUnit.
6. Supports parallel test execution using Selenium Grid.
7. Reduces repetitive testing work.

13. What are the limitations of Selenium?

1. It is mainly designed for web application testing.
2. It cannot directly automate desktop applications.
3. It cannot directly automate CAPTCHA.
4. It does not provide built-in test reporting.
5. It requires programming knowledge for advanced automation.

14. What is Regression Testing?

Regression testing is performed to ensure that new code changes or updates do not affect the existing functionality of an application.

Example: After adding a new payment feature to an e-commerce website, testing the existing login and shopping cart functionality again.

15. What is the difference between Selenium IDE, WebDriver and Grid?

Selenium IDE – Records and plays back browser actions.

Selenium WebDriver – Automates browser actions using code.

Selenium Grid – Executes tests across multiple machines and browsers.

16. Why are you learning Selenium with Java?

I am learning Selenium with Java because Java is widely used in automation testing. Selenium WebDriver supports Java, and Java helps write reusable and maintainable automation scripts.

17. Can Selenium be used for API Testing?

Selenium is primarily designed for web browser automation, not API testing. Tools such as REST Assured and Postman are commonly used for API testing.

18. What is a Test Case?

A test case is a set of steps, inputs, conditions and expected results used to verify whether a particular functionality works correctly.

Example: A login test case checks whether a user can log in using valid credentials.

19. What is a Test Script?

A test script is a set of instructions written in a programming language to execute a test case automatically.

Example: A Java Selenium script that opens a browser, enters login credentials and clicks the Login button.

20. What is the difference between a Bug and a Defect?

A defect is a problem or deviation from the expected requirement in software. A bug is a commonly used term for an error or fault found in the application during development or testing.
